# VitalHealth Clinic - Incident Analysis & Secret Management

## Contexto del Proyecto
VitalHealth Clinic gestiona una red de clínicas médicas que procesa expedientes electrónicos y datos sensibles de pacientes (información HIPAA). Una alerta de seguridad indicó que credenciales críticas del portal de pacientes y llaves de acceso a servicios en la nube se filtraron y accesibles públicamente durante 72 horas.

## Objetivo de la Actividad
El equipo debe analizar los impactos de esta filtración, evaluar los vectores de exposición, diseñar un plan de respuesta a incidentes inmediato y proponer una arquitectura segura basada en gestión centralizada de secretos.
